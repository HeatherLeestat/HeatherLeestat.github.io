# 명사 + To + 동사 패턴 정리

## 1. 구조

`명사 + to + 동사`

- 뜻: “~할 명사” 또는 “~하는 것”
    
- 역할: 명사를 꾸며주는 **형용사 역할의 부정사**
    

---

## 2. 대표 예문

|명사|패턴 예문|해석|
|---|---|---|
|plan|I had a plan **to visit Paris**.|나는 파리 방문 계획이 있었다.|
|decision|She made a decision **to quit her job**.|그녀는 일을 그만두기로 결정했다.|
|homework|He has homework **to finish before Monday**.|그는 월요일 전까지 끝낼 숙제가 있다.|
|someone|We need someone **to help us**.|우리를 도와줄 사람이 필요하다.|
|book|I found a book **to read on vacation**.|나는 휴가 때 읽을 책을 찾았다.|
|task|There is a task **to complete by Friday**.|금요일까지 끝낼 과제가 있다.|
|message|He left a message **to answer later**.|그는 나중에 답할 메시지를 남겼다.|
|place|We need a place **to stay for the weekend**.|우리는 주말 동안 머물 곳이 필요하다.|

## 3. 학습용 빈칸 연습

|문장|빈칸|
|---|---|
|I had a plan **____**.|(visit Rome)|

|He has homework **____**.|(do tonight)|
|We need someone **____**.|(guide the tour)|

|There is a task **____**.|(prepare the slides)|
|He left a message **____**.|(check tomorrow)|
|We need a place **____**.|(rent near the beach)|

---

## 4. 요약 포인트

1. **명사 + to + 동사** → 명사를 꾸며주며 “무엇을 하는 것인지” 설명
    
2. 주로 사용되는 명사: **plan, decision, homework, someone, book, task, message, place**
    
3. to를 빼면 문법적으로 맞지 않음 → 반드시 **to + 동사 원형** 사용
