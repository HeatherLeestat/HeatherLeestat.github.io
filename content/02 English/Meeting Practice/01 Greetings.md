# 상황 설명
회의 시작 시 인사 및 간단한 안부, 회의 목적 소개

# 기본 표현
- "Good morning everyone, hope you’re doing well."
- "Thank you for joining today’s meeting."
- "Let’s get started. The purpose of today’s meeting is..."
- "I appreciate everyone making time for this session."
- "Before we begin, does anyone have updates to share?"

# 응용 문장
- "We have a tight schedule today, so let’s keep each topic brief."
- "Let’s quickly review the agenda for today."
- "I hope everyone received the pre-meeting materials."
- "Please feel free to jump in if you have comments."

# Role-play 연습
| 내가 말하는 문장 | 상대방 예상 반응 | 내 대응 |
|----------------|----------------|---------|
| "Good morning everyone, let’s get started." | "Morning!" | "Great, let’s start with the first topic." |
| "Thank you all for joining." | "No problem." | "Perfect, let’s dive in." |
| "Before we begin, does anyone have updates?" | "I have an update on X." | "Thank you, let’s include it in the agenda." |
